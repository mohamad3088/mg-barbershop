# MG Barbershop

Premium one-page website voor MG Barbershop, Tiensestraat 188, 3000 Leuven.

## Gegevens van de zaak (verzameld 6 okt 2026)
- Telefoon: 016 22 22 11 (vast nummer, dus geen WhatsApp-knop; boeken gaat via bellen)
- Google: 4,9★ uit 234 reviews, geen website (alleen een Instagram-link)
- Instagram: [@mg.barbershopp](https://www.instagram.com/mg.barbershopp/) (±220 volgers, 276 posts, actief)
- Uren: Google zegt ma–zo 09:30–20:00, Instagram-bio zegt 10:00–20:00. **Navragen.**
- Diensten (van de prijslijst op hun raam): knippen, baard, knippen + baard, knippen + baard + wassen, baard + epileren + wassen, kinderen tot 12 jaar, wassen

## Nog te bevestigen voor oplevering
- [ ] **Prijzen**: de bedragen in `script.js` (bovenaan, `PRICES`) zijn richtprijzen
- [ ] Openingsuren (`HOURS` in `script.js`)
- [ ] Toestemming om de Instagram-foto's te gebruiken (of betere foto's vragen in hoge resolutie)
- [ ] Logo: `img/logo.svg` is nagetekend van hun Instagram-logo. Vraag het originele bestand.

## Bestanden
- `index.html`, `styles.css`, `script.js`: statische site, geen build nodig
- `img/`: webfoto's + logo-varianten (goud/crème/donker)
- `img/raw/`: originele Instagram-downloads + `urls.txt`

Lokaal bekijken: `python -m http.server 5174` in deze map, daarna http://localhost:5174.
